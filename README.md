# The Pause Chooses Me

A short poem about agency: the power to stop and to stay. One concrete moment — a hand lifted from the keyboard, a sentence left unsent — and the quiet power in choosing not to act.

## How to run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if set). The program is deterministic: every run writes byte-identical output.
